# ⏰ Бот-напоминалка для Telegram

Простой бот на Python: нажимаете кнопку «➕ Новое напоминание», пишете «Позвонить маме», выбираете время — и в нужный момент бот присылает «⏰ **Напоминание!** Позвонить маме».

## Что умеет бот

**Кнопки внизу экрана** (появляются после `/start`):

| Кнопка | Что делает |
|---|---|
| ➕ Новое напоминание | Спрашивает, что напомнить, а потом когда: кнопками (+10 мин, +30 мин, +1 час, +3 часа, завтра в 9:00) или текстом, например `18:30` |
| 📋 Мои напоминания | Список напоминаний, под ним кнопки 🗑 для удаления |
| ❓ Помощь | Подробная справка |

**Команды** (для тех, кто любит печатать; они же в синей кнопке «Меню» слева от поля ввода):

| Команда | Что делает |
|---|---|
| `/start` | Приветствие и кнопки меню |
| `/help` | Описание всех команд с примерами |
| `/new` | Новое напоминание по шагам (как кнопка) |
| `/remind 18:30 Позвонить маме` | Создаёт напоминание одной строкой. Если 18:30 сегодня уже прошло — напомнит завтра |
| `/list` | Показывает активные напоминания |
| `/delete 3` | Удаляет напоминание №3 |
| `/cancel` | Отменяет начатое создание напоминания |

## Из чего состоит проект

```
reminder-bot/
├── bot.py            ← весь код бота (с подробными комментариями)
├── requirements.txt  ← список библиотек, которые нужно установить
├── .env.example      ← образец файла настроек
├── .env              ← ваши настройки с токеном (создадите сами на шаге 5)
├── .gitignore        ← какие файлы не загружать на GitHub
└── reminders.json    ← появится сам, когда создадите первое напоминание
```

## Как это работает (прочитайте перед запуском — дальше будет понятнее)

**Токен.** Каждый бот в Telegram имеет «пароль» — токен. Его выдаёт официальный бот @BotFather. Наша программа предъявляет токен серверам Telegram и говорит: «Я — вот этот бот, дай мне его сообщения».

**Polling (опрос).** Бот не «сидит» внутри Telegram. Это обычная программа на вашем компьютере, которая каждую секунду спрашивает у Telegram: «Есть новые сообщения для меня?». Отсюда главное следствие: **бот работает, только пока запущена программа**. Выключили компьютер — бот молчит.

**Обработчики.** Когда приходит сообщение `/list`, библиотека `telebot` находит функцию, помеченную `@bot.message_handler(commands=["list"])`, и вызывает её. Каждая команда — своя функция.

**Поток (thread).** Бот должен делать два дела одновременно: отвечать на команды и следить за часами. Поэтому в программе два «работника»: основной отвечает на сообщения, а второй в начале каждой минуты проверяет, не пора ли что-то напомнить.

**JSON-файл.** Если хранить напоминания только в памяти программы, они исчезнут при перезапуске. Поэтому бот записывает их в `reminders.json` — обычный текстовый файл, его можно открыть Блокнотом и посмотреть. Если бот был выключен в момент напоминания, он пришлёт его сразу после запуска с пометкой, что опоздал.

**Два вида кнопок.** В Telegram кнопки бывают двух видов:
- **Reply-клавиатура** — кнопки внизу экрана вместо обычной клавиатуры («➕ Новое напоминание» и другие). Нажатие просто отправляет текст кнопки как сообщение, и бот ловит его так же, как команду.
- **Inline-кнопки** — прикреплены под конкретным сообщением (🗑 в списке, «+10 мин» при выборе времени). Нажатие не пишет ничего в чат, а присылает боту короткую метку, например `del:3` — «удалить №3».

**Диалог по шагам.** Когда вы нажимаете «➕ Новое напоминание», бот запоминает: «этот чат сейчас на шаге *жду текст*». Следующее ваше сообщение он воспринимает как текст напоминания и переходит к шагу «жду время». Это называется *состояние диалога* — в коде это словарь `states`.

**Оформление.** Жирный текст и курсив делаются HTML-тегами: `<b>жирный</b>`, `<i>курсив</i>`. Всё, что пишет пользователь, бот перед вставкой в сообщение «обезвреживает» функцией `escape()` — иначе напоминание «купить <молоко>» сломало бы сообщение: Telegram принял бы `<молоко>` за тег.

## Шаг 1. Установите Python

Python — язык, на котором написан бот. Программа на Python — это текстовый файл, а чтобы его выполнить, нужен сам Python.

1. Откройте https://www.python.org/downloads/ и нажмите большую жёлтую кнопку **Download Python 3.x**.
2. Запустите скачанный файл.
3. ⚠️ **Внизу первого окна поставьте галочку «Add python.exe to PATH»** — это самое важное. Без неё команда `python` не будет работать в терминале.
4. Нажмите **Install Now** и дождитесь окончания.

**Проверка.** Откройте терминал: нажмите `Win + R`, введите `cmd`, нажмите Enter. В чёрном окне наберите:

```
python --version
```

Должно появиться что-то вроде `Python 3.13.1`. Если вместо этого открылся Microsoft Store или ничего не вывелось — Python не установлен или не стоит галочка PATH (см. «Частые проблемы» внизу).

> **Что такое PATH?** Это список папок, где Windows ищет программы, когда вы вводите команду. Галочка добавляет туда папку Python — и команда `python` начинает находиться из любого места.

## Шаг 2. Получите токен у @BotFather

1. Откройте Telegram и найдите **@BotFather** (у настоящего есть синяя галочка).
2. Нажмите **Start** и отправьте команду `/newbot`.
3. BotFather спросит **имя** бота — его видят пользователи. Например: `Мои напоминания`.
4. Потом спросит **username** — адрес бота. Он должен быть уникальным и заканчиваться на `bot`. Например: `varti_remind_bot`. Если занято — придумайте другой.
5. BotFather пришлёт сообщение с токеном — длинной строкой вида:
   ```
   7412345678:AAH4kLm9pQrStUvWxYz0123456789abcdef
   ```
   Скопируйте её целиком.

> 🔒 **Токен — это пароль.** Кто знает токен, тот полностью управляет ботом. Не отправляйте его никому, не публикуйте в чатах и на GitHub. Если токен всё-таки утёк — в @BotFather отправьте `/revoke`, выберите бота и получите новый (старый перестанет работать).

## Шаг 3. Откройте терминал в папке проекта

Все следующие команды нужно выполнять **внутри папки** `reminder-bot`, иначе Python не найдёт файлы.

Самый простой способ: откройте папку `reminder-bot` в Проводнике, кликните в **адресную строку** сверху (где написан путь), сотрите всё, напишите `cmd` и нажмите Enter. Откроется терминал, уже «стоящий» в этой папке.

Проверить, что вы в нужном месте, можно командой `dir` — в списке должны быть `bot.py` и `requirements.txt`.

## Шаг 4. Создайте виртуальное окружение и установите библиотеки

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Что делает каждая строка:

1. **`python -m venv venv`** — создаёт папку `venv` с «личной копией» Python для этого проекта. Зачем: библиотеки этого бота будут жить в ней и не смешаются с библиотеками других проектов. Если проект больше не нужен — удаляете папку, и никаких следов в системе.
2. **`venv\Scripts\activate`** — «включает» это окружение в текущем окне терминала. В начале строки появится `(venv)` — значит, всё получилось. Делать это нужно **каждый раз**, когда открываете новый терминал для работы с ботом.
3. **`pip install -r requirements.txt`** — `pip` — это «магазин приложений» для Python. Команда читает список из `requirements.txt` и скачивает три библиотеки:
   - `pyTelegramBotAPI` — умеет разговаривать с Telegram (в коде подключается как `telebot`);
   - `python-dotenv` — читает токен из файла `.env`;
   - `tzdata` — база часовых поясов (на Windows её нет, а без неё бот не поймёт, что такое «московское время»).

> На macOS и Linux команды чуть другие: `python3 -m venv venv` и `source venv/bin/activate`.

## Шаг 5. Впишите токен в файл .env

Токен не пишут прямо в код: если когда-нибудь выложите код на GitHub, токен утечёт вместе с ним. Поэтому он живёт в отдельном файле `.env`, который в GitHub не попадает (об этом заботится `.gitignore`).

В том же терминале выполните:

```
copy .env.example .env
notepad .env
```

Первая команда делает копию образца под именем `.env`, вторая открывает её в Блокноте. Замените `вставьте_сюда_токен` на ваш токен — **без пробелов и кавычек**:

```
BOT_TOKEN=7412345678:AAH4kLm9pQrStUvWxYz0123456789abcdef
TIMEZONE=Europe/Moscow
```

Сохраните (`Ctrl + S`) и закройте Блокнот.

`TIMEZONE` — часовой пояс. Для Ростова-на-Дону и Москвы оставьте `Europe/Moscow`. Он нужен, чтобы «18:30» значило 18:30 по вашим часам, даже если потом запустите бота на сервере в другой стране.

## Шаг 6. Запустите бота

```
python bot.py
```

Если всё в порядке, появится:

```
2026-09-29 18:25:03  INFO  Проверка напоминаний запущена
2026-09-29 18:25:03  INFO  Бот @varti_remind_bot запущен. Напоминаний в файле: 0. Остановить — Ctrl+C
```

Теперь откройте своего бота в Telegram (ссылку `t.me/...` давал BotFather), нажмите **Start** — бот поздоровается, а внизу появятся кнопки меню.

**Быстрая проверка:** нажмите **➕ Новое напоминание**, напишите `Проверка` и выберите **+10 мин** — или напишите время на 1–2 минуты вперёд, например `18:27`. Когда время придёт, бот пришлёт напоминание, а в терминале появится строка `Отправил напоминание №1`.

> Если вы обновили код, а бот уже был запущен, — остановите его (`Ctrl + C`) и запустите снова: запущенная программа не видит изменений в файле. Чтобы появились новые кнопки меню, отправьте боту `/start`.

**Остановить бота:** в окне терминала нажмите `Ctrl + C`. Напоминания сохранятся в `reminders.json`.

**Запустить снова** (например, на следующий день):

```
cd путь\к\папке\reminder-bot
venv\Scripts\activate
python bot.py
```

Или откройте терминал через адресную строку Проводника, как на шаге 3, и выполните две последние команды.

## Важно знать

- **Бот работает, пока открыт терминал и включён компьютер.** Закроете окно — бот перестанет отвечать. Напоминания при этом не потеряются: после запуска бот пришлёт все пропущенные с пометкой, что опоздал. Чтобы бот работал круглосуточно, его запускают на сервере (VPS) — это следующий шаг, когда разберётесь с основами.
- **Запускайте бота только в одном окне.** Если запустить две копии с одним токеном, Telegram не поймёт, кому отдавать сообщения, и выдаст ошибку `409 Conflict`.
- **Каждый видит только свои напоминания.** Бот запоминает, из какого чата пришла команда, и `/list`, `/delete` работают только с напоминаниями этого чата.
- **Номера напоминаний не сдвигаются.** Если удалить №2, у остальных номера не поменяются. Так `/delete` никогда не удалит «не то» (подробнее — в комментариях в `bot.py`).

## Частые проблемы

| Что видите | Что делать |
|---|---|
| `python` открывает Microsoft Store или пишет «не является внутренней командой» | Python не установлен или не отмечена галочка PATH. Запустите установщик Python ещё раз → **Modify** → на втором экране отметьте **Add Python to environment variables**. Затем закройте и заново откройте терминал |
| `venv\Scripts\activate` в PowerShell ругается на «выполнение сценариев отключено» | Вы в PowerShell, а не в cmd. Проще всего открыть `cmd` (шаг 3). Или запускать без активации: `venv\Scripts\python bot.py` |
| `ModuleNotFoundError: No module named 'telebot'` | Не установлены библиотеки или не активировано окружение: в начале строки нет `(venv)`. Выполните `venv\Scripts\activate`, затем `pip install -r requirements.txt` |
| `Не найден токен бота` | Нет файла `.env` или в нём остался образец. Повторите шаг 5. Проверьте, что файл называется именно `.env`, а не `.env.txt` |
| `Telegram не принял токен (ошибка 401)` | Токен скопирован с ошибкой. Скопируйте заново из @BotFather, без пробелов |
| `409 Conflict` | Бот уже запущен в другом окне. Закройте лишнее окно |
| Бот не отвечает в Telegram | Проверьте, что в терминале бот запущен и нет ошибок, и что вы нажали Start в чате с ботом |
| Напоминание пришло на час раньше/позже | Неверный `TIMEZONE` в `.env` |

## Как устроен код

Откройте `bot.py` — он разделён на восемь частей, у каждой заголовок в комментарии:

1. **Настройки** — чтение токена и часового пояса из `.env`, проверка, что всё на месте, включение HTML-оформления.
2. **Хранилище** — загрузка и сохранение `reminders.json`, создание и удаление напоминаний, «замок» для безопасной работы двух потоков.
3. **Время** — разбор строки `18:30`, расчёт «сегодня или завтра», «через 10 минут», красивый вывод «завтра в 09:00».
4. **Кнопки и тексты** — клавиатуры, тексты приветствия и справки, оформление списка.
5. **Команды и кнопки меню** — по функции на каждую команду и кнопку; словарь `states` для диалога.
6. **Диалог создания и inline-кнопки** — шаги «что напомнить → когда», обработка нажатий 🗑, «+10 мин», «Отмена».
7. **Проверка по времени** — цикл, который раз в минуту рассылает напоминания.
8. **Запуск** — проверка токена, меню команд, запуск второго потока и опроса Telegram.

## Что можно добавить потом

Хорошие упражнения, если захотите развивать бота:

- напоминания на конкретную дату: `/remind 05.10 18:30 День рождения`;
- повторяющиеся напоминания: каждый день или каждую неделю;
- кнопка «Отложить на 10 минут» прямо под пришедшим напоминанием;
- запуск на сервере, чтобы бот работал круглосуточно.
